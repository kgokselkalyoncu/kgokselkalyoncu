# React Workshops
Bu klasör, React ile ilgili atölye çalışmaları ve örnek projeleri içerir. Her alt klasör farklı konu veya uygulama örneklerini barındırır; içinde genellikle kısa açıklama, kurulum ve çalışma adımları ile örnek kod bulunur.

## İçerik
- Temel React kavramları ve örnekleri
- Bileşen yapısı (fonksiyonel ve sınıf bileşenleri)
- State, Props ve veri akışı
- React Hooks (useState, useEffect, useRef, custom hooks)
- Yönlendirme ve çok sayfalı uygulamalar
- Durum yönetimi (Context API, Redux vb.)
- Test örnekleri ve proje tabanlı uygulamalar

## Klasörler ve tahmini işlevleri
- 00-Basic/ — React’in temel kavramlarını gösteren başlangıç örnekleri ve küçük alıştırmalar. (Tahmini: giriş seviyesi)
- 01-Beginner-Projects/ — Yeni başlayanlar için tamamlanmış veya adım adım proje örnekleri (todo list, küçük UI bileşenleri). (Tahmini: başlangıç/orta seviye)
- 02-Intermediate-Projects/ — Bileşen kompozisyonu, orta düzey state yönetimi ve temel yönlendirme içeren projeler. (Tahmini: orta seviye)
- 03-Advanced-Projects/ — Performans optimizasyonu, karmaşık state akışı ve ileri seviye React desenleri içeren projeler. (Tahmini: ileri seviye)
- 04-Expert-Projects/ — Büyük ölçekli mimari, ileri durum yönetimi (Redux/RTK/GraphQL), test ve dağıtım örnekleri. (Tahmini: uzman/seviye)
