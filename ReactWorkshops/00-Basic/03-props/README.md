# 03 - Props

📌 Componentler arasında veri aktarmak.

## 📖 Açıklama
Props, parent component’ten child component’e veri taşımamızı sağlar.  
Ayrıca `props.children` ile içerik geçebiliriz.

## 🎯 Öğrenme Hedefleri
- Props kullanımı
- props.children mantığı
- Tekrar kullanılabilir component yazmak

## 📝 Görevler
- `Welcome` componenti yap, `name` props alsın
- İsimleri farklı farklı göster
- `Card` componenti yap, içine çocuk eleman ekle

## 💡 Ekstra
Bir `Button` componenti yap, props ile `text` alsın.
